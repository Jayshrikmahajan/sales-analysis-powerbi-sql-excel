# Retail Sales Performance & Strategic Insights

This project presents a comprehensive analysis of retail sales data, focusing on sales performance, profitability, and customer insights. The analysis was conducted using Excel, SQL, and Power BI to transform raw data into meaningful business insights.

This project was completed as part of an **internship task offered by Maincraft Technology**, demonstrating practical application of data analysis and business intelligence concepts.

## 🔧 Tools & Technologies

• Power BI – Dashboard and data visualization
• Microsoft Excel – Data cleaning and preprocessing
• SQL (MySQL) – Data handling and querying
• DAX – Measures and calculations

## 📊 Key Highlights

• Sales Performance Analysis (2.33M revenue, 12.56% margin)
• Regional Analysis (West region highest contributor)
• Category Insights (Technology leads revenue share)
• Monthly Trends (Peak in November & December)
• Discount Impact (High discounts reduce profitability)
• Customer Analysis (Top 10 customers drive significant revenue)

## 📌 Outcome

The project provides actionable insights to improve profitability, optimize discount strategies, and support data-driven decision-making.
